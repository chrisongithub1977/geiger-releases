# Geiger Desktop — releases

Official download home for the **Geiger Desktop** companion app for the
[GeigerBox](https://geigerbox.com) desk-side Claude usage monitor.

- **Download the latest version:** see [Releases](https://github.com/chrisongithub1977/geiger-releases/releases/latest)
  - Windows: the `-setup.exe`
  - macOS (Apple Silicon): the `.dmg`
- Installed apps auto-update from this repository.

Geiger is an independent product. Not affiliated with or endorsed by Anthropic.
